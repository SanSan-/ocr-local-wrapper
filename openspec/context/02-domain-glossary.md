# Проектные обозначения

| Термин | Значение и основной источник |
|--------|------------------------------|
| Профиль модели | Согласованный набор исходных настроек выбранного семейства: [OCR-010](../specs/image-ocr/spec.md#requirement-ocr-010-согласованные-профили) |
| Готовый TXT | Уже существующий пользовательский текстовый результат: [OCR-007](../specs/image-ocr/spec.md#requirement-ocr-007-существующий-txt-и-force) |
| OCR-кеш | Сохранённый результат со сведениями о входе, модели и параметрах: [OCR-006](../specs/image-ocr/spec.md#requirement-ocr-006-кеш-по-пути-и-метаданным) |
| Пул модели | Удержание одной загруженной модели для повторных операций веб-процесса: [OCR-011](../specs/image-ocr/spec.md#requirement-ocr-011-повторная-загрузка-и-измерение) |
| KV-кеш | Промежуточные состояния предыдущих токенов при генерации, отдельные от кеша результата |
| force | Явный режим нового распознавания с обновлением выбранного результата: [OCR-007](../specs/image-ocr/spec.md#requirement-ocr-007-существующий-txt-и-force) |
| Переход на CPU | Повтор загрузки после ошибки графического устройства, отличающийся от первоначального выбора процессора: [OCR-005](../specs/image-ocr/spec.md#requirement-ocr-005-различие-cpu-перехода) |
| INT8 | Представление весов восьмибитными целыми числами: [OCR-004](../specs/image-ocr/spec.md#requirement-ocr-004-устройство-и-квантование) |
| SSE | Поток событий от сервера к браузеру: [WEB-004](../specs/local-web/spec.md#requirement-web-004-sse-и-результат) |

Общеупотребительные инженерные сокращения здесь не определяются. Словарь поясняет обозначения,
а условия их применения остаются в соответствующих требованиях.
