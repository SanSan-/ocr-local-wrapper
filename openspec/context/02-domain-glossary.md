# Словарь

| Термин           | Значение                                                                                 |
|------------------|------------------------------------------------------------------------------------------|
| OCR              | Распознавание одного изображения местной GLM-OCR или PaddleOCR-VL-1.6                    |
| Профиль          | Идентификатор модели, её prompt, максимумы токенов/пикселей и минимум площади            |
| Готовый TXT      | Пользовательский результат, сохраняемый без force; не доказательство модели и параметров |
| OCR-кеш          | JSON с отдельной записью для пути изображения и настроек; size/mtime проверяют вход      |
| Pool модели      | Одна загруженная модель веб-процесса; повторное использование и выгрузка при смене       |
| KV-кеш           | Временные состояния предыдущих токенов внутри генерации; не кеш готового TXT             |
| force            | Обойти кеш, повторно распознать и заменить выбранный TXT                                 |
| CPU fallback     | Повтор загрузки на CPU после GPU-ошибки; отличается от CPU при отсутствии CUDA           |
| Upload           | Копия изображения внутри resources/uploads с именем SHA-256                              |
| SSE              | События конкретного веб-запуска; не устойчивая история                                   |
| Статический PASS | Проверка документа/структуры; не распознавание изображения                               |
