# ADR-001: Общий локальный OCR-конвейер

## Статус

Принято.

## Контекст

CLI и веб должны возвращать одинаковый результат распознавания и одинаково обрабатывать ошибки.

## Решение

Обе оболочки вызывают run_ocr с OcrOptions. GLM-OCR или PaddleOCR-VL-1.6 загружается из локального каталога по общему
профилю; внешний API и автоматическая загрузка модели не используются.

## Последствия

Проверка изображения и готового результата предшествует загрузке модели. Оболочки отвечают за ввод и отображение;
предметная логика остаётся общей.

## Альтернативы

Независимые реализации CLI и веб расходились бы в обработке кеша, force и ошибок. Внешний сервис требует отдельного
контракта доступа и передачи данных.

## Условия пересмотра

Изменение рабочего входа OCR, порядка проверок или поддерживаемого способа загрузки модели.
