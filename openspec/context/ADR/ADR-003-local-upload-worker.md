# ADR-003: Копия upload и один рабочий поток

## Статус

Принято.

## Контекст

Веб-пользователь выбирает изображение и наблюдает прогресс распознавания.

## Решение

Загрузка создаёт копию с именем по SHA-256 внутри uploads; recognize ограничивает путь этим каталогом. Одновременно
допускается один активный поток, прогресс передаётся через SSE log/done.

## Последствия

Loopback-запуск не является Host/Origin-защитой. Очередь событий и задачи находятся в памяти; восстановление после
перезапуска не предусмотрено. Upload читается целиком. С 2026-09-20 сбой thread.start освобождает активный слот;
загрузка весов и профильные результаты определены в [ADR-004](ADR-004-model-profiles-and-runtime.md).

## Альтернативы

Надёжная очередь, лимит upload, восстановление снимка и middleware требуют самостоятельного решения и проверок. Их
наличие нельзя выводить из единственного рабочего потока.

## Условия пересмотра

Изменение конкурентности, ограничения входа, доступа к вебу или доставки прогресса.
