# Продукт

Локальная утилита распознаёт одно изображение через заранее подготовленную GLM-OCR или PaddleOCR-VL-1.6. CLI и веб
используют общий сервис; веб показывает изображение, текст, выбор модели, её промпт/лимиты и времена стадий.

Входы: JPEG/PNG/WebP/BMP. Совпавший профильный кеш возвращается до загрузки весов; force запускает OCR заново. Старые
TXT/кеши сохраняются, но не считаются автоматически результатом другой модели. Веб использует отдельный TXT для каждой
комбинации параметров, CLI защищает существующий выход.

Веб загружает одну модель лениво и переиспользует её между запросами. GPU default — BF16/FP16, INT8 включается явно;
генерация использует KV-кеш. Локальные веса не скачиваются автоматически.

PDF, пакетный OCR, структурированные таблицы и внешние API не являются готовыми возможностями. Запись TXT/кеша прямая;
loopback не заменяет Host/Origin-защиту.
