# Антипаттерны

Таблица помогает выбрать требование при характерной ошибке; условия и результаты определены в указанных контрактах.

| Ошибочное предположение                                          | Владелец правила                                                                                                                    |
|------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------|
| Путь и параметры одной модели подходят любой модели              | [OCR-003/009/010](../specs/image-ocr/spec.md)                                                                                       |
| INT8 всегда даёт максимальную скорость                           | [OCR-004](../specs/image-ocr/spec.md)                                                                                               |
| CPU при отсутствии CUDA и повтор после ошибки GPU — один режим   | [OCR-005](../specs/image-ocr/spec.md)                                                                                               |
| Любой готовый TXT доказывает совпадение модели и параметров      | [OCR-006/007](../specs/image-ocr/spec.md)                                                                                           |
| Прямая запись результата гарантирует атомарность                 | [OCR-008](../specs/image-ocr/spec.md)                                                                                               |
| Загрузку весов нужно повторять при каждом запросе                | [OCR-011](../specs/image-ocr/spec.md)                                                                                               |
| Измерение прогретой модели описывает первый запрос               | [ENG-003](../specs/engineering-governance/spec.md#requirement-eng-003-приёмка-качества-и-производительности-ocr)                    |
| Привязка к локальному адресу подтверждает защиту Host/Origin     | [WEB-001](../specs/local-web/spec.md)                                                                                               |
| SSE хранит устойчивую историю                                    | [WEB-004](../specs/local-web/spec.md)                                                                                               |
| Успех имитации доказывает качество кириллицы реальной модели     | [ENG-003](../specs/engineering-governance/spec.md#requirement-eng-003-приёмка-качества-и-производительности-ocr)                    |
| Для Paddle нужно читать отсутствующий image_processor.min_pixels | [OCR-010](../specs/image-ocr/spec.md#requirement-ocr-010-согласованные-профили); [пример процессора](../../tests/test_inference.py) |
