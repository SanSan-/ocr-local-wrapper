# ocr-local

Локальное распознавание текста на изображениях с помощью моделей GLM-OCR и PaddleOCR-VL-1.6.
Приложение работает через командную строку и веб-интерфейс, использует заранее загруженные модели
и сохраняет результат в текстовый файл.

## Структура проекта

```text
.
├── ocr_local/             # Распознавание текста и пользовательские интерфейсы
│   ├── cli.py             # Работа через командную строку
│   ├── service.py         # Общий сервис распознавания
│   ├── model_profiles.py  # Профили моделей и параметры распознавания
│   ├── utils/             # Работа с файлами, моделями и кешем
│   └── web/               # Локальный веб-интерфейс
│       └── static/        # Страница, стили и сценарии браузера
├── scripts/               # Проверки моделей и измерение производительности
├── tests/                 # Автоматические проверки
├── openspec/              # Требования и документация проекта
│   ├── context/           # Начало работы, архитектура, словарь и решения
│   ├── specs/             # Спецификации распознавания, интерфейса и правил работы
│   └── changes/           # Изменения проекта
├── resources/             # Изображения, результаты и кеш
├── logs/                  # Журналы приложения
├── run_web.ps1            # Запуск веб-интерфейса
├── pyproject.toml         # Метаданные пакета и настройки проверок
└── requirements.txt       # Зависимости Python
```
