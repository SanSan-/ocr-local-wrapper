# AGENTS

Первым и единственным входным файлом проектного контекста прочитай [openspec/context/00-start-here.md](openspec/context/00-start-here.md). Остальные документы выбирай по его маршруту.

Требования проекта и архитектурные решения находятся в OpenSpec. Обязательны [инженерная спецификация](openspec/specs/engineering-governance/spec.md) и [локальное приложение](openspec/specs/engineering-governance/reference/project-specific.md).

Общие инструкции работы агента и профиль Python читай по `instructions/README.md` относительно каталога применённых глобальных инструкций. Состояние задач — в [changes/README.md](openspec/changes/README.md).

## Продолжение задачи

Для активного изменения используй закреплённый файл продолжения, иначе `openspec/changes/<change-id>/evidence/context-summary.md` со ссылкой из design или tasks. При прямой работе со спецификациями без активного изменения сводку и результаты проверки передавай в ответе; журнал проверок исходной спецификации не создавай.

## Сохранность при документальной работе

Неизменность исходников, тестов, зависимостей, пользовательских оригиналов и результатов, весов, кешей и резервных копий проверяй по SHA-256 в затронутой области.

## Ограниченный аудит контекста

Для отдельно и явно подключённого аудита выбирай изменившиеся активные изменения: не более трёх изменений и 192 KiB содержимого суммарно. Архивы, полные деревья доказательств и история сессий исключены. Это местный бюджет уже разрешённого аудита; порядок работы задают общие инструкции.
